# ShatrunZ - Simple Start Guide

## ✅ EASIEST WAY TO START

Just use the shell script (it handles everything):

```bash
cd /Users/nehatiwari/localcode/shatrunZ
./start.sh
```

That's it! The script will:
1. Activate the virtual environment automatically
2. Install dependencies if needed
3. Start both server and inspector
4. Show all logs in the terminal

## 🌐 Then Open Browser

http://localhost:8000

## 🎮 Test the Aggressive AI

1. Click **AIvAI** tab
2. Click **Start AI**
3. Watch the terminal for live analysis!

## 🛑 To Stop

Press `Ctrl+C` in the terminal

---

## Alternative: Manual Start (if you want more control)

```bash
cd /Users/nehatiwari/localcode/shatrunZ

# Activate virtual environment
source .venv/bin/activate

# Start with Python
python start.py
```

But the shell script (`./start.sh`) is easier!
